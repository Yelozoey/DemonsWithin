# 《心魔》同局对手建模与交手记录

## 试玩和对比

打开灰盒对战场景进入 Play。心魔默认使用在线适应。按 **F1** 查看有效机会数、双方距离段、早弹与后撤的估计值、心魔上一个出招及其基线选择。概率旁的括号是按近因衰减后的样本权重。**F2** 循环切换本局自适应、固定出招与 [LLM 战术](LlmTactics.md)，**F3** 导出当前对局 JSON。**R** 重开时清空本局证据和记录，保留所选模式。

可以分别在快击起手后过早按 Q、等接近命中帧再按 Q，观察心魔是否先提高再降低延迟击倾向。另一组对比是在看到起手后反复向外移动，观察突刺是否更常被选中。中键锁定后用 S 后撤便于重复这个情境。每组用 F2 切换模式并重开，尽量在相同距离重复。

## 有效应对机会

心魔实际起手时，以当前招式、距离和玩家当时的动作状态开一个应对窗口。玩家在起手时处于硬直或动作锁定、已经超出招式范围和余量，或招式在当步判定时，样本只进入交手记录。挥击在命中前被打断也只记录。一次有效交手结算一次，包括等待、主动防御、反击和实际离开范围等结果。

反应通过角色公开动作和实际位移识别。弹反的有效窗口若在预计接触前已经关闭，该次记为早弹。后撤由玩家自身沿两人连线向外移动的距离判断，避免把心魔自行退开当成玩家反应。当前分类取该窗口内首次可识别的反应。距离允许有约 0.25 米的余量，主动移动累积约 0.28 米后才归类。有效机会最终以挥击落空、命中或防御结果结算。当前灰盒以可行动状态与距离估计是否可感知前兆。

## 预测与选招

本地统计按「心魔招式 × 距离段」维护。每个新有效机会使旧证据按 0.88 衰减。早弹从快击样本估计，后撤从同距离段的样本估计。对应距离样本偏少时回退到较宽范围。约 2.35 个有效权重且平滑后的估计超过阈值，才会影响选招。

- 对快击频繁早弹时，心魔提高延迟击优先级。
- 面对起手反复后撤，心魔提高较远突刺的优先级。
- 调整只在心魔可以开始新动作且候选招式达到距离要求时生效。每三次起手中的第一次保留快击基线，用来继续观察玩家是否改变节奏。两条适应规则同时满足时，选择证据支持的概率较高者。

固定模式继续记录证据，按快击、延迟击、突刺循环。输入缓存、碰撞、命中和防御窗口仍由战斗系统进行判定。

## 导出的记录

F3 把 JSON 写入 Unity 的 `Application.persistentDataPath/Duels`，Console 会显示完整路径。文件包含对局 ID、当前战斗步、输入动作及缓冲状态、交手结果、可用／排除原因、反应帧、心魔选招时的模式与统计权重。导出时正在进行的交手单独标记，可以与已经结算的样本一起查看。

输入记录来自本局 Input Actions 的游戏动作，仅供调试。对手建模读取交手中已表现出来的动作与位移。内存保存最近 4,096 条输入、512 条命中结果及 512 条应对记录，导出注明被淘汰的条数。
