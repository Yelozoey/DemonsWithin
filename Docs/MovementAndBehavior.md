# 《心魔》胶囊移动、攻击碰撞盒与行为树

## 移动与滑步

原有角色模型跟着胶囊一起按 50 Hz 固定步跳到新坐标，Animator 同样按固定步采样，镜头则每个渲染帧更新。渲染快于战斗步时，屏幕会接连看到相同的角色坐标，再看到一次完整步长的变化。锁定移动的方向切换还会从零开始播放新片段，使脚步相位出现额外跳变。[Unity 物理插值说明](https://docs.unity3d.com/cn/2023.1/Manual/rigidbody-interpolation.html)

胶囊位置和碰撞继续由 CharacterController 在固定步更新。移动输入先投影到镜头轴或靶向轴，再转换为水平目标速度。用独立的步行加速度、奔跑加速度、刹车和反向加速度限制**速度向量**的变化，碰撞后用实际位移计算速度。闪避使用锁定于起手的方向，以及动作资产里的位移距离和时长。前段较快，末段递减，运动仍会撞到墙。无敌窗口沿用动作资产防御帧。

模型、地面标记和镜头使用相同的插值位姿，Animancer 每渲染帧取样。攻击等其余动作的根位移按固定步提交到胶囊。走跑的循环速率由胶囊实际速度和表现配置的 Reference Speed 决定。靶向移动在方向分界加入滞后区，切换走路循环时保留步态相位。两项措施减轻滑步与抽动。压脚和骨骼步幅修正目前留给具体动画调优。[Unity CharacterController.Move](https://docs.unity3d.com/ScriptReference/CharacterController.Move.html) · [Epic 步幅修正与胶囊速度](https://dev.epicgames.com/documentation/unreal-engine/pose-warping-in-unreal-engine)

## 自由镜头

未锁定时，角色胸口的目标屏幕坐标约在横向 42%。镜头在角色右肩后方，构图给右侧保留视野。自由 Walk／Run、Sprint、锁定的原型垂直 FOV 分别是 48°、54°、51°，自由视角随 Sprint 起止平滑切换。锁定下可以走路和八向奔跑，实际进入 Sprint 时自动解除。公开演示可参考肩后构图，具体角度采用本原型的可调参数。把 Duel Camera Rig 挂到 Duel Camera 可以保存独立镜头配置。[《对马岛之魂》官方实机演示](https://blog.playstation.com/2020/05/12/thursdays-state-of-play-is-all-about-ghost-of-tsushima/)

## 攻击碰撞盒

打开 **Tools → Demons Within → 动作编辑器**，选择攻击动作并拖动时间尺。蓝色线框是攻击盒，进入命中窗口时变红。默认盒由原招式距离和角度生成。在右侧预览拖动箭头、面手柄或旋转环即可编辑，首次拖动会保存为该动作的自定义盒。

实战在命中时间窗内用同一个盒和对方 CharacterController 胶囊求交。每招最多结算一次。预览展示的是相对于角色根节点的范围。当前每个动作使用一个盒，旋转和中心可调整。挂在刀尖并随帧移动的判定体属于后续扩展。AI 的出招接近距离仍读取招式的距离字段，改了自定义盒的前伸量时，可同步校准 AI 用的距离。

## 心魔行为树

打开 **Tools → Demons Within → 心魔行为树**。左侧画布显示运行时实际读取的 `DemonBehaviorTree` 资产。默认根节点是优先选择器，四个子节点从左到右按优先级排列。滚轮围绕指针缩放画布，中键拖动平移，「适合视图」重新显示整棵树。

点击根节点，在右侧参数区编辑出手余量与基线探测间隔。点击子节点，可编辑该节点的启用状态、优先级及相关数值。接近节点控制移动强度，站位节点控制后退强度与过近距离，攻击节点控制出手间隔。进入 Play 后，活跃节点与连线变为青色，右侧显示选中节点的状态。参数改动写入同一资产。

F2 循环切换本局自适应、固定轮换和 LLM 战术。使用 LLM 模式时，右侧同时显示请求或战术状态、最近一次实际出招和战术名称。接入方式见[同局 LLM 战术](LlmTactics.md)。
