# 《心魔》移动、对峙镜头与动作编辑

## 试玩

打开 `Assets/DemonsWithin/Scenes/PhaseOneArena.unity` 后进入 Play 模式。默认是自由镜头，WASD 以镜头为轴进入 Run，角色朝移动方向转身。点击游戏画面后移动鼠标旋转镜头，Esc 释放鼠标。按**鼠标中键**切换锁定。锁定下 W/S 沿双方连线进退，A/D 环绕，使用八向 Run。按住 **Ctrl** 走路，按住 **Shift + 方向键**进入 Sprint 并自动解除锁定。只按 Shift 时保持原锁定状态。**空格**闪避，右键格挡，Q 弹反，F 识破，E 延迟攻击，T 突刺／空中收尾，V 空战起手。R 重开，F1 显示动作帧和当前派生。

输入绑定在 `Assets/DemonsWithin/Resources/DuelControls.inputactions`。

通过 **Tools → Demons Within → 打开连招训练场** 打开 `TrainingArena`。训练机器人留在原地并承受反复命中。HUD 显示当前连击、最长连击和命中总数。**R** 重置，**F1** 查看动作帧、转向状态和已缓存派生，**F4** 可更换练习动作。

## 地面连段

| 起手 | 左键续招 | 变招 |
| --- | --- | --- |
| **左键** | 两段基础拳 → `FightFist04_2`，共三段 | 第二击命中后可用 **E** 接延迟攻击，或用 **V** 接起跳 |
| **C** | `FightFist02_1 → 2a` | **E** 可命中确认后改接 `2b`，两种收尾命中后均可用 **V** |
| **W + C** | `Fist05_1 → 2 → 3 → 4`，共四段 | 第二拳稍晚按左键，改走 `Kick_Combo02_1 → 2 → 3`，共五段 |
| **A/D + C** | `Kick_Combo03_1 → 2 → 3 → 4`，共四段 | 第二段起须命中才能继续 |
| **S + C** | `Kick_Combo01_1 → 2 → 3 → 4 → 5`，共五段 | 第二段起须命中才能继续 |

建议先锁定训练机器人，在近身按方向和 C 起手，再逐击按左键。锁定下方向键选择起手，持续按住同一方向时仍面向目标，换方向可以在转向窗口内转身。第四、第五段是路线里的动作数。对手能否在两段之间行动取决于命中硬直以及下一招的实际接触帧。

这些拳脚沿用 Root 片段。部分腿法的平面位移已按近身距离缩放，避免连踢时从对手侧面冲过去。可在动作时间轴的「根运动位移倍率」继续微调。

`Fist05_2` 命中后，同一左键输入分为 **第 3–15 帧**的四拳线与**第 16–35 帧**的拳转腿线，两条线分别从第 17 和第 24 帧开始派生。练拳转腿时先等第二拳打完，看到 **F1** 显示 16 帧后再按下一次左键。编辑器区分「缓存截止帧」和「派生截止帧」，两者均不含截止帧。过早、过晚、结果不符和被打断会显示在训练 HUD。

中立 **C** 的 `FightFist02_1` 命中窗为 **9–15 帧**。左键与 E 从第 3 帧接收输入，分别从第 18 帧和第 31 帧派生，截止帧为 41 和 49。

其余地面动作按用途继续接入。先用独立拳脚补短起手、距离覆盖和收尾，再为跑动、闪避结束与反制成功后的入口各选片段。成套动作保留原生顺序，按站位、命中结果或输入时机引入少量跨套分支。每加一条路线，在训练场核对距离与接触点，再用可格挡或闪避的对手验证硬直间隙。《鬼泣4》的四击和停顿变招提供了同键分支的参考，《仁王3》按架势区分动作和成本，《街霸》的开发说明提供了区分真连与可反制间隙的判据。[Capcom《鬼泣4》官方攻略](https://static.capcom.com/devilmaycry/guides/DMC4_pp1CU.pdf) · [Team Ninja《仁王3》战斗系统](https://teamninja-studio.com/nioh3/sch/system/index.html) · [Capcom 帧优势说明](https://game.capcom.com/cfn/sfv/column/131611?lang=en)

## 空战派生

| 地面输入 | 起跳片段 | 首次左键派生 |
| --- | --- | --- |
| **V** | `Air_Attack_04_1` | `01 → 02 → 03` |
| **W + V** | `Air_Attack_04` | `Air_Attack_Combo01` 两段 |
| **A/D + V** | `Air_Attack_05_1` | `02 → 03` |
| **S + V** | `Air_Attack_05` | `Air_Attack_Combo02` 两段 |

基础左键连击第二段和 `FightFist02` 的两条收尾均可在命中后按 **V** 进入起跳。四组起跳可以在离地前缓存左键，等实际升空后派生。**E** 可以在指定命中后改接另一段，**T** 可以提前转到 `03` 收尾。地面进入空中需要起跳曲线把胶囊抬离地面，空中片段只在离地状态接入。派生后沿当前速度与重力下落，触地后播放落地动作。实战起跳招命中可挑空另一角色，训练机器人固定在原处。

## 镜头与移动

Unity 6.6 内置 Cinemachine 的 Brain 在自由肩后镜头和对峙镜头之间淡化。锁定镜头围绕双方中点构图，向侧面取景，随距离拉开以保留双方身位。锁定时选定取景一侧，解除锁定后接回自由视角。《对马岛之魂》的公开决斗画面提供了双方同框和侧向构图的参考，本工程的角度、镜头阻尼和锁定规则属于《心魔》的原型设计。[Sucker Punch 的 GDC 决斗示例](https://media.gdcvault.com/gdc2026/Slides/Fishman_Theodore_honing_the_blade_evolving_combat_for_ghost_of_yotei.pdf) · [Cinemachine Brain](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineBrain.html)

Walk、Run、Sprint 和闪避由角色胶囊驱动。步行按方向选择 Start、Loop、Stop，Run 使用八向循环，Sprint 使用 Lucy 的 Sprint Loop 和 Stop。地面攻击通过 `OnAnimatorMove` 提交根位移，起跳攻击的高度曲线在固定步驱动胶囊。受击根据攻击者在目标局部空间中的方位切换前、后、左、右、左前、右前反应，前上方落击使用 `Hit_FD`，被挑空使用空中受击。移动、镜头、碰撞盒和行为树的当前配置见[胶囊移动与行为树](MovementAndBehavior.md)。

当前 `LucyAnimation.Idle` 直接绑定 `Lucy_Fight_Idle_Inplace`。角色静止且当前动作或移动停止片段结束后回到该槽位。普通 Idle 与 Fight Idle 之间目前没有状态切换规则。

## Unity 编辑器面板

| 路径 | 配置 |
| --- | --- |
| **Tools → Demons Within → 连招配置** | 切换「地面战斗」或「空中战斗」，从「起手 → 实战入口」选路线。点动作节点可预览和进入动作时间轴，点派生线可预览衔接、修改输入、结果条件与帧范围。「设为地面起手」可配置 C 及三个方向槽位 |
| **Tools → Demons Within → 动画过渡预览** | 在左侧选 Player 或 Demon、前后片段。拖动下面的片段调整重叠时长，点时间尺定位。播放／暂停和右侧角色预览使用同一进度。修改会保存到该角色使用的表现配置 |
| **Tools → Demons Within → 动作编辑器** | 左侧编辑时间轴和选中项，右侧看角色和攻击盒。选一条派生后可对照转向、命中、输入缓存和派生区间。拖「转向窗口」两端修改帧范围 |

过渡面板采用两条重叠片段轨。玩家和心魔预览各自的角色预制体，当前共用 Lucy 表现配置，拖动修改的片段对适用于双方。[Unity 动画过渡](https://docs.unity3d.com/cn/current/Manual/class-Transition.html)

战斗工具的预览地面以 **0.5 米**为一格。Root 片段的根位移相对于固定网格播放，Inplace 片段使用烘焙后的姿态。动作时间轴里的攻击盒跟随预览角色，手柄修改的是角色局部坐标。

动作编辑器用 **总帧数**、**命中起始**、**命中截止** 描述一招。以 60 fps、总长 56 帧、命中起始 25、截止 32 为例，前摇 25 帧、命中 7 帧、后摇 24 帧。命中区间包含起始帧。每个动作至多结算一次命中。修改帧数会改变播放速率，因此替换动画后要检查动作的实际接触姿势。

主动攻击默认在命中起始帧关闭转向。闪避读取相应 Root 片段的首段明显平面位移，保留至少约 45 毫秒的输入时间，随后固定胶囊的闪避方向。双人演出在主动方的转向窗口内整体转动，双方保持相对站位。可在「动作参数」恢复自动窗口。受击、反制硬直和战败会锁定转向。

攻击盒可直接在右侧预览编辑。用彩色箭头移动盒子，用面上的方块改尺寸，用圆环调整水平旋转。红框表示当前命中帧。右键拖动改变视角，滚轮缩放。编辑结果直接保存到实战读取的动作资产，可用 Unity 撤销。

在动画轨追加片段可组成一招。每个片段可设置入点、出点和淡化时间，表现配置中同一方向的片段对规则优先。动作时间轴使用绝对动作帧触发标记。事件轨把名字传给角色 `FighterPresentation` 的 `Named Event`，音效轨引用 AudioClip，特效轨引用预制体并可设置相对位置与存续时间。编辑器预览展示姿势和混合，音效、特效和 Root Motion 碰撞可在 Play 模式检查。动作分段、通知标记和混合参数的设计参考了 Montage 的对应功能。[Epic Animation Montage Editor](https://dev.epicgames.com/documentation/unreal-engine/animation-montage-editor-in-unreal-engine) · [Animancer 过渡机制](https://kybernetik.com.au/animancer/docs/changes/animancer-v8-0/)

默认动作资产位于 `Assets/DemonsWithin/Combat/Actions/`。角色可在 `DuelFighter` 的 **Loadout** 指定自有动作、连招与表现配置。Lucy 的徒手片段仍是暂用资源，突刺和识破更换正式素材后需要重新校准窗口与接触姿势。

Lucy 全套战斗片段可在对战中按 **F4** 搜索与演示。攻击起手和后续派生从连招树配置。素材计数、双人配对和调校入口见 [Lucy 战斗动画库](LucyCombatLibrary.md)。
